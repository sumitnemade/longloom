Every claim below is backed by a runnable example or a test in the repository.

🔌Any LLM, any storage

One seam each: init_llm maps 8 providers — or bring a bare str → str function. Memory → SQLite → Postgres → MySQL → MongoDB → Supabase, or subclass one ABC with four methods.

🧵Measured no-loss mode

Verbatim extraction preserves 100% of planted facts on hostile document mixes — logs, JSON, tables — where naive summarization drops 2–10%.

⚡Parallel map

max_workers=8 fans the map phase across a thread pool with shared rate-limit pacing. Measured 4× on an 8-chunk document.

🔁Checkpoint / resume

Map results are checkpointed per chunk. resume=True after a crash re-maps only the missing chunks — nothing twice.

🗄️Lives in YOUR database

Embed into existing tables with table=, columns= and multi-tenant namespace= — no dedicated database, your migrations own the DDL.

📡Observable

Structured on_event stream with per-call token usage and durations — forward to OpenTelemetry or Datadog. Retry-After, jitter and pacing are built in.

How it works

The context window only ever sees chunks and compact element lists — the document never has to fit.

CHUNK
line-aware splitting, persisted to your storage
MAP
one LLM call per chunk — parallel, checkpointed
MERGE
hierarchical combine, window-sized groups
REPAIR
bounded condensation, only if still too big

verified at the end of every run: chunk losslessness, fact preservation, token accounting

60-second quickstart

# pip install longloom
import os
from longloom import MapReduceProcessor, SQLiteContextStore, init_llm, PromptTemplates

processor = MapReduceProcessor(
    llm=init_llm("nvidia", "nvidia/nemotron-3-ultra-550b-a55b",
                 api_key=os.environ["NVIDIA_API_KEY"], thinking=False),
    store=SQLiteContextStore("ctx.db"),
    max_chunk_tokens=3000, max_context_tokens=8192,
    prompts=PromptTemplates.for_extraction(),   # no-loss verbatim mode
    max_workers=4,                              # parallel map
)

result = processor.process(annual_report, task="Summarize the key findings")
print(result["final_result"])

Enterprise-ready out of the box

🔐 Explicit credentials

Keys are constructor arguments — the library never reads the environment and never logs secrets. Point it at your vault.

🏢 Your databases, your schema

Custom tables, columns and tenant namespaces; DDL stays with your migrations. MSSQL and Oracle dialects included.

🛰️ Your LLM gateway

Custom base_url and headers for vLLM, LiteLLM or Azure APIM — wire-verified, keys optional for local endpoints.

🧹 PII & retention

Pluggable scrubber rewrites content before storage; delete_sessions_older_than(days) sweeps every backend.
